The  <a href="https://training.linuxfoundation.org/certification/kubernetes-and-cloud-native-security-associate-kcsa/" target="_blank">Kubernetes and Cloud Native Security Associate (KCSA)</a> exam is a an interesting one. Much like the other associate level exam, <a href="https://www.rubysecurity.org/kubernetes/kubestronaut/kcna" target="_blank">Kubernetes and Cloud Native Associate (KCNA)</a>, this is a traditional question and answer exam. A lot of the object objectives on this exam is theory based, like Cloud security models, Security compliance frameworks, and general basic level of Pod/Container security related configuration in Kubernetes.

The major motivation for me on embarking on this <a href="https://www.cncf.io/training/kubestronaut/" target="_blank">Kubestronaut</a> journey has been to learn new things Kubernetes that I otherwise wouldn't know about. Certainly on all exams thus far have been the case. On this exam in particular I just learned about Pod Security Standards (PSS) and Pod Security Admission (PSA), which were new to me even after working with Kubernetes on an almost daily bases the last five years! (I use Kubernetes Admission Controllers instead)

I'm almost at the finish line on achieving <a href="https://www.cncf.io/training/kubestronaut/" target="_blank">Kubestronaut</a>, now the final exam I need to pass is arguably the most difficult one. [Certified Kubernetes Security Specialist (CKS)][]

### Difficult Level

This was an easy exam. However unlike the scenario exam exercises or other question and answer exams where I have somewhat of an idea of what the answer will be. I felt as if on the questions that I answered wrong, were completely guesses on my part. Although the exam is easy in my point of view, I can certainly see it a being tricky to others. There were a few questions that touch topics I have zero to no working knowledge about, like AppArmor and seccomp.
